# 스마트 테이블 주문 시스템 데모

React와 Vite 기반의 매장용 테이블 주문 시스템 데모입니다. 고객이 테이블에서 메뉴를 담고 주문/직원 호출을 전송하면, 점주 관리자 화면에서 주문 상태·테이블 점유·호출·메뉴 품절 관리를 즉시 확인할 수 있도록 구성했습니다.

## 데모 기능

- **테이블 주문 화면**: 테이블 선택, 카테고리별 메뉴 탐색, 장바구니 수량 변경, 결제 방식 선택, 주문 전송
- **직원 호출**: 물/냅킨/앞접시/직원 호출 요청을 관리자 화면으로 전달
- **점주 관리자 화면**: 신규 접수 → 조리 중 → 서빙 완료 → 결제 완료 상태 전환
- **운영 대시보드**: 완료 매출, 진행 매출, 이용 테이블, 미처리 주문, 인기 메뉴 TOP 3 표시
- **테이블 맵/메뉴 운영**: 테이블별 진행 금액 확인 및 메뉴 판매중/품절 토글

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드 확인:

```bash
npm run build
```
